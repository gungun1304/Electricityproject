## ⚡ Project: Electricity Bill Calculation System

### 📌 Project Overview
The **Electricity Bill Calculation System (`one.py`)** is a Python-based application that automates monthly electricity bill generation based on unit consumption slabs, fixed charges, and applicable taxes.

### ✨ Key Features
* **User Input:** Takes Consumer ID, Consumer Name, and Total Units Consumed.
* **Slab-Wise Calculation:** Automatically calculates charges according to different unit consumption slabs.
* **Tax & Fixed Charges:** Adds meter rent and applicable duty/tax automatically.
* **Clean Bill Summary:** Prints a formatted, easy-to-read receipt on the console.
